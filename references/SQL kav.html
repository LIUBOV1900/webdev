📚 SQL кавычки

Названия полей

Тип Пример Кавычки
Без пробелов name, age Нет
С пробелами "Birth Year" Двойные " "
✓ SELECT name, age FROM users
✓ SELECT id, gender FROM artists
✓ SELECT "Birth Year" FROM artists
✓ SELECT "First Name", "Last Name" FROM users

Значения в WHERE

Тип Пример Кавычки
Строка 'Female' Одинарные ' '
Число 1900, 25 Нет
✓ WHERE gender = 'Female'
✓ WHERE name = 'Ivan'
✓ WHERE "Birth Year" < 1900
✓ WHERE age >= 25

Частые ошибки

✗ WHERE gender == "Female"
✓ WHERE gender = 'Female'

✗ SELECT Birth Year FROM artists
✓ SELECT "Birth Year" FROM artists

Python + SQLite

cursor.execute("SELECT * FROM artists WHERE gender = 'Female'")

cursor.execute('SELECT * FROM artists WHERE "Birth Year" < 1900')
💡 Внешние кавычки — это кавычки Python для строки
💡 Внутренние кавычки — это кавычки SQL для значений
💡 Они должны быть разными, чтобы Python не запутался!
