Классификация функций проекта

В таблице функции распределены по ролям: работа с базой данных, состояние пользователя, маршрутизация, представление и обработка ответов. Некоторые функции могут выполнять сразу несколько ролей, например result() является маршрутной функцией и при этом рендерит страницу результата.

Категория Функция Назначение Где используется / кто вызывает Что возвращает / результат
БД: подключение и запросы open() Открывает соединение с базой данных SQLite и создаёт курсор. Вызывается внутри функций модуля базы данных перед выполнением запросов. Не возвращает значение; заполняет глобальные переменные conn и cursor.
БД: подключение и запросы close() Закрывает курсор и соединение с базой данных. Вызывается после завершения работы с базой в функциях модуля базы данных. Не возвращает значение; закрывает соединение.
БД: подключение и запросы do(query) Выполняет SQL-запрос и сохраняет изменения в базе. Используется в clear_db() и create(). Не возвращает значение; вызывает conn.commit().
БД: структура и данные clear_db() Удаляет таблицы quiz_content, question, quiz. Вызывается для очистки структуры базы перед повторным созданием таблиц. Не возвращает значение; удаляет таблицы.
БД: структура и данные create() Создаёт таблицы quiz, question, quiz_content. Вызывается для первичной инициализации структуры базы данных. Не возвращает значение; создаёт таблицы, если их ещё нет.
БД: структура и данные add_questions() Добавляет подготовленные вопросы в таблицу question. Вызывается для наполнения базы данных вопросами. Не возвращает значение; добавляет записи в таблицу.
БД: структура и данные add_quiz() Добавляет подготовленные викторины в таблицу quiz. Вызывается для наполнения базы данных викторинами. Не возвращает значение; добавляет записи в таблицу.
БД: структура и данные add_links() Добавляет связи между викторинами и вопросами в таблицу quiz_content. Вызывается вручную для связывания викторин с вопросами. Не возвращает значение; добавляет связи в таблицу.
БД: чтение и логика get_quises() Получает список всех викторин из таблицы quiz. Используется в quiz_form() для формирования списка викторин. Возвращает список кортежей, например (id, name).
БД: чтение и логика get_question_after(question_id, quiz_id) Получает следующий вопрос викторины после вопроса с указанным id. Используется в main() и test(). Возвращает кортеж с данными вопроса или None, если вопросов больше нет.
БД: чтение и логика check_answer(q_id, ans_text) Проверяет, совпадает ли ответ пользователя с правильным ответом. Используется в save_answers(). Возвращает True, если ответ верный, иначе False.
БД: отладка и демо show(table) Выводит все строки указанной таблицы в консоль. Используется в show_tables(). Не возвращает значение; печатает результат запроса.
БД: отладка и демо show_tables() Выводит содержимое таблиц question, quiz, quiz_content. Вызывается для отладки и просмотра содержимого базы. Не возвращает значение; печатает данные в консоль.
БД: отладка и демо main() Демонстрирует работу модуля базы данных, например выводит вопрос. Точка запуска скрипта базы данных. Не возвращает значение; выводит данные в консоль.
Сессия и состояние start_quiz(quiz_id) Инициализирует состояние викторины в сессии пользователя. Вызывается в index() при выборе викторины. Не возвращает значение; записывает данные в session.
Сессия и состояние end_quiz() Очищает состояние викторины после завершения тура. Вызывается в result(). Не возвращает значение; очищает session.
Маршруты / контроллеры index() Обрабатывает главную страницу: показывает выбор викторины или принимает выбранный вариант. Правило маршрута /, методы GET и POST. Возвращает HTML-форму выбора викторины или перенаправление на test().
Маршруты / контроллеры test() Обрабатывает страницу текущего вопроса: показывает вопрос, принимает ответ, завершает тур при отсутствии вопросов. Правило маршрута /test, методы GET и POST. Возвращает HTML-страницу вопроса или перенаправление на result() / index().
Маршруты / контроллеры result() Показывает результат тура и завершает викторину. Правило маршрута /result. Возвращает HTML-страницу результата; вызывает end_quiz().
Представление / рендеринг quiz_form() Готовит страницу выбора викторины, передавая список викторин в шаблон. Вызывается из index() при GET-запросе. Возвращает результат render_template('start.html').
Представление / рендеринг question_form(question) Готовит страницу вопроса, перемешивает варианты ответов и передаёт их в шаблон. Вызывается из test(), если есть следующий вопрос. Возвращает результат render_template('test.html').
Обработка ответа save_answers() Читает ответ пользователя из формы, проверяет его и обновляет счётчики в сессии. Вызывается из test() при POST-запросе. Не возвращает значение; изменяет данные в session.

Условные обозначения: БД — база данных. Маршруты / контроллеры — функции, которые привязаны к URL и обрабатывают запросы. Представление / рендеринг — функции, которые подготавливают HTML-страницы через шаблоны.
