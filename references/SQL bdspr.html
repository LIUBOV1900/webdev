📊 SQL Шпаргалка: Влияние команд на базу данных

🟢 НЕ МЕНЯЮТ
🟠 МЕНЯЮТ ДАННЫЕ
🔴 МЕНЯЮТ СТРУКТУРУ
⚪ УПРАВЛЕНИЕ
🟢 НЕ МЕНЯЮТ БД (Только чтение)
SELECT
Извлекает данные из таблиц. База остается нетронутой, результат только в памяти.
EXPLAIN
Показывает план выполнения запроса или структуру таблицы. Только информация.
🟠 МЕНЯЮТ ДАННЫЕ (DML)
INSERT
Добавляет новые строки в существующую таблицу.
UPDATE
Изменяет значения в существующих строках. Обычно с WHERE!
DELETE
Удаляет строки из таблицы. Место на диске освобождается не сразу.
MERGE
Комбинированная операция: INSERT, UPDATE или DELETE (UPSERT).
🔴 МЕНЯЮТ СТРУКТУРУ (DDL)
CREATE
Создает новые объекты: БД, таблицы, индексы, представления.
ALTER
Изменяет структуру объекта: добавляет/удаляет колонки, меняет типы.
DROP
Полностью удаляет объект из БД вместе со всеми данными.
TRUNCATE
Удаляет все данные из таблицы, но структура остается. Сбрасывает ID.
⚪ УПРАВЛЕНИЕ (DCL/TCL)
GRANT/REVOKE
Управляют правами доступа: кто может читать/писать данные.
COMMIT
Сохраняет все изменения текущей транзакции навсегда.
ROLLBACK
Отменяет изменения транзакции, возвращая БД в прежнее состояние.
⚠️ Ловушка: CREATE TABLE AS SELECT... или SELECT ... INTO меняют структуру БД, хотя содержат SELECT!
