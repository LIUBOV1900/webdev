🗒 Шпаргалка по шаблонам
{{ выражение }} — подставить значение в текст.
{% if условие %} … {% else %} … {% endif %} — ветвление.
{% for x in список %} … {% endfor %} — цикл по списку.
{% for id, name in список_пар %} — цикл по парам значений.
{% set имя = значение %} — создать переменную.
Функции: len(), str(), int(). Условия: ==, !=, <, >, and, or, not.
