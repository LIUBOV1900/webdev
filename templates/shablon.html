06
Новая тема

Что такое шаблон?

  • Шаблон содержит всю информацию о внешнем виде страницы.
  • Шаблон не содержит конкретных данных.
  • В шаблоне указано, куда какие данные нужно вставлять.

📄 Шаблон — документ, оформленный по правилам HTML

Мы создаём структуру из тегов, в которую потом вписываем нужные данные. Программа состоит из изолированных частей: теги + данные.

07
Новая тема

Преимущества шаблонов

✏️ Легко менять

Внесение изменений в оформление — правка одного файла-шаблона.

🎯 Единый стиль

Не нужно каждый раз заново писать код, чтобы оформить разные страницы одинаково.

🤝 Командная работа

Над изолированными частями могут работать разные специалисты: дизайнер и программист.

✅ Меньше ошибок

HTML-код удобно собирать: теги и данные не перемешаны.

08
Новая тема · Обработка шаблонов

Подключаем шаблон: render_template

from flask import Flask, render_template

def index():
    """ функция обрабатывает шаблон index.html
        и возвращает получившийся документ """
    return render_template('index.html')

render_template обрабатывает шаблон и возвращает получившийся текст — готовый HTML-документ.

09
Расположение файлов на диске

Где искать шаблоны и ресурсы?

import os

folder = os.getcwd()  # рабочая папка

app = Flask(__name__,
    template_folder=folder, # шаблоны
    static_folder=folder)   # ресурсы
  • static_folder — папка с ресурсами: картинки, готовые страницы, таблицы стилей;
  • template_folder — папка с шаблонами;
  • по умолчанию Flask ищет ресурсы в подпапке static, шаблоны — в подпапке templates.
10
Функция обработки шаблонов

Передаём данные в шаблон

render_template('index1.html',
    header="А если попробовать",
    text="<i>Курсив?</i>")
  • имя шаблона — строка с именем файла (из папки template_folder);
  • поименованные параметры — их значения будут использованы в шаблоне;
  • передать можно любые объекты: строки, переменные, списки, словари, функции.
11
Процесс обработки шаблона

Подстановка значений: {{ выражение }}

<!-- index.html -->
<body>
  <h2>{{ header }}</h2>
  <p>{{ text }}</p>
</body>
  • обрабатываются только элементы в фигурных скобках — остальной текст возвращается как есть;
  • {{ выражение }} — команда подставить значение выражения в текст;
  • в выражении можно использовать переданные параметры, операции с ними и вызовы функций.

Элементы оформления — в шаблоне, данные не должны содержать оформление.

12
Процесс обработки шаблона

Вызов функций в шаблоне: подключаем CSS

<link rel="stylesheet"
      href="{{ url_for('static', filename='style.css') }}">
  • в двойных фигурных скобках подставляется результат вызова функции;
  • правило "static" применяется для ссылок на статичные ресурсы;
  • url_for доступна процессу обработки шаблона без особых указаний;
  • файл должен находиться в папке static_folder.
13
Управление процессом обработки

Операторы: {% оператор %}

При обработке шаблона могут потребоваться циклы и ветвления — например, для формы выбора викторины или списка вопросов.

  • {% оператор %} — команда управления процессом обработки;
  • обработка шаблонов не зависит от отступов!
  • весь текст после оператора считается вложенным в него, пока не встретится завершающий оператор.
14
Операторы шаблонов

Условный оператор: {% if %}

{% if header %}
  <h2>{{ header }}</h2>
{% else %}
  <h2>Нет заголовка</h2>
{% endif %}
  • {% if условие %} — текст выведется, если условие верно;
  • {% else %} — если условие неверно;
  • {% endif %} — конец условия;
  • условия как в Python: ==, !=, <, >, and, or, not. Переменная без значения возвращает False.
15
Операторы шаблонов

Цикл: {% for %}

Соберём список выбора викторины — по элементу для каждой записи из базы:

<select name="quiz">
{% for id, name in q_list %}
    <option value="{{ id }}">{{ name }}</option>
{% endfor %}
</select>
  • {% for переменные in перечень %} — цикл с поочерёдным использованием значений;
  • {% endfor %} — конец цикла.

Применяем в викторине

Шаблон вопроса: test.html

Данные об ответе отправляются на ту же страницу: GET — показать вопрос, POST — обработать ответ.

<h1>{{ question }}</h1>
<form method="post" action="test">
  <input type="hidden" name="q_id"
         value="{{ quest_id }}">
  {% for answer in answers_list %}
  <input type="radio" name="ans_text"
         value="{{ answer }}"> {{ answer }}
  {% endfor %}
  <input type="submit" value="Ответить">
</form>
  • type="hidden" — хранит номер вопроса, но ничего не показывает;
  • type="radio" — переключатели: выбрать можно только один ответ;
  • в шаблон передаются: вопрос, номер, перемешанный список ответов — правильный в коде не виден.

Применяем в викторине

Сохранение и проверка ответа

def save_answers():
    answer   = request.form.get('ans_text')
    quest_id = request.form.get('q_id')
    session['last_question'] = quest_id
    session['total'] += 1
    if check_answer(quest_id, answer):
        session['answers'] += 1
  • request.form.get(имя) — читаем данные из формы;
  • в сессию: номер вопроса, total — сколько задано, answers — сколько верных;
  • check_answer() живёт в db_scripts.py: ищет верный ответ в БД и возвращает True/False;
  • страница результата result.html покажет session['answers'] и session['total'].
