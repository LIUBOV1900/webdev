04
Новая тема

Что такое база данных?

База данных (БД) — информация, хранящаяся упорядоченным способом и предназначенная для определённой цели.

СУБДСистема управления базами данных — программа для создания БД и работы с ними.
SQLStructured Query Language — язык структурированных запросов: им читают и записывают данные в БД.

Простейшая схема: программа → SQL-запрос → СУБД → база данных.

08
Команды SQL

Создание таблицы — CREATE TABLE

CREATE TABLE questions (
    question         TEXT,
    max_score        INT,
    correct_answer   TEXT,
    incorrect_answer TEXT
);
  • указываем имя таблицы;
  • в скобках — столбцы и их типы: TEXT — текст, INT — целое число;
  • имена — строчными буквами, слова через подчёркивание: max_score.
09
Команды SQL

Добавление записей — INSERT INTO

INSERT INTO questions
    (question, max_score, correct_answer, incorrect_answer)
VALUES ('2x2=4', 1, 'Верно', 'Неверно');
  • после INSERT INTO — имя таблицы;
  • в скобках — столбцы, которые заполняем;
  • после VALUES — значения в том же порядке.

Команды SQL

Получение данных — SELECT

Условия и сортировка

🧮 Условия в WHERE

  • сравнение текста;

SQL + Python

Соединение и курсор

import sqlite3

conn = sqlite3.connect("questions.db")  # база — в файле questions.db
cursor = conn.cursor()               # объект для отправки запросов
connect(файл)создаёт объект-соединение с базой
cursor()курсор — «посыльный» для запросов
14
SQL + Python

Выполнение запроса и результат

cursor.execute('SELECT *
    FROM questions
    WHERE max_score > 2')

data = cursor.fetchall()
conn.commit()

print(data)
  • execute() — выполняет запрос; многострочный текст — в тройных кавычках;
  • fetchall() — собирает результат в список кортежей: каждый кортеж — одна запись;
  • commit() — сохраняет изменения в базе.

Результат: [('Ep = mgh', 3, 'Верно', 'Неверно'), ('Куликовская битва', 3, '1380', '1242'), …]

15
Безопасность

Как вставить переменную в запрос?

⚠️ Способ 1: конкатенация

query = 'SELECT * FROM questions
    WHERE max_score > ' + str(score)
cursor.execute(query)

Опасно! Сайт уязвим к SQL-инъекциям — запуску вредоносного SQL-кода.

✅ Способ 2: плейсхолдеры

cursor.execute('SELECT * FROM questions
    WHERE max_score > (?)', [score])

Отлично! Злоумышленник не сможет подставить вредоносный код.

(?) — плейсхолдер «держит место»; переменные из списка подставляются по порядку. Плейсхолдеров может быть несколько.
