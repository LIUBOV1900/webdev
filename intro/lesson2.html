веб-страниц

Почему HTML-тегов мало для красоты сайта — и как CSS превращает обычную страницу в сайт с уникальным стилем.

01
Повторение

Что мы уже умеем

На прошлом уроке мы изучили HTML — язык, который задаёт структуру страницы:

  • структура документа: <html>, <head>, <body>;
  • заголовки <h1>–<h6> и абзацы <p>;
  • списки <ul> / <ol> с пунктами <li>;
  • ссылки <a> и изображения <img>;
  • выделения <b>, <i>, комментарии <!-- -->.

Структура готова. А как насчёт красоты?

02
Обсуждение

Как выглядят настоящие сайты?

Большинство сайтов отличаются особым оформлением и уникальным, легко узнаваемым стилем: цвета, шрифты, отступы, рамки.

🤔 Вопрос

Получится ли оформить такой сайт с помощью изученных тегов HTML?

💬 Ответ

Пока нет — инструментов мало. Сегодня познакомимся с более мощным средством оформления!

03
Элементы оформления в HTML

Управление шрифтом тегами

📏 Шкала размеров

Размер шрифта в HTML — условные единицы от 1 до 7, по умолчанию — 3. <big> увеличивает на 1, <small> уменьшает на 1. Теги можно вкладывать друг в друга.

🔤 Тег <font>

color — цвет текста, size — размер, face — тип шрифта. Атрибуты можно использовать выборочно.

<font color="red" size="5" face="Arial">Важный текст</font>
<p>Обычный, <big>крупнее</big> и <small>мельче</small> текст</p>
04
Проблема

Что не так с этим подходом?

Представь: хотим, чтобы все заголовки на сайте были одного цвета.

Придётся каждый раз повторять теги и атрибуты у каждого заголовка.

В сайте десятки страниц — значит, копировать их на каждую страницу!

Захотим сменить стиль всего сайта? Придётся менять атрибуты каждого тега на каждой странице… 😱

…или освоить более эффективный инструмент работы со стилями.

05
Новая тема

CSS — каскадные таблицы стилей

CSS (Cascading Style Sheets) — язык, который описывает оформление веб-страниц отдельно от их содержимого.

🎯 Что такое стиль?

Стиль — набор параметров, с помощью которых можно настроить внешний вид всех одинаковых элементов страницы. Например, сразу всех заголовков первого уровня.

Одно правило в CSS → применяется ко всем подходящим элементам сразу.

06
Новая тема

Преимущества CSS

🧩 Разделение труда

Вёрстка и дизайн живут в разных файлах — над ними можно работать параллельно.

📱 Адаптация

Стили определяют вид страницы для разных устройств: монитора, смартфона, планшета, принтера.

🎨 Больше возможностей

У CSS гораздо больше способов оформить элементы, чем у HTML-тегов.

⚡ Быстрая загрузка

Файл стилей попадает в кэш браузера: код страниц уменьшается, загрузка ускоряется.

07
Новая тема

Как создать таблицу стилей?

🔧 Внутри тега

<p style="color:red">…</p>

Быстро, но только для одного элемента.

📄 Внутри <head>

<style>
  p { color: red; }
</style>

Стили для одной страницы.

🗂️ Файл .css 🔥

<link rel="stylesheet"
      href="styles.css">

Наиболее предпочтительный способ. Оба файла — в одной папке.

Убедиться в мощи метода: csszengarden.com — один и тот же текст в десятках совершенно разных оформлений. Всё меняется одним CSS-файлом! ✨

08
Новая тема

Синтаксис CSS

h1 {
    color: red;
    font-size: 40px;
}
  • селектор — элемент, который оформляем (h1, p…);
  • свойство — что меняем;
  • значение — как меняем;
  • каждая пара свойство: значение; заканчивается точкой с запятой;
  • пар может быть сколько угодно.

Один стиль для нескольких селекторов: h1, h2, h3 { color: navy; } — остальные свойства останутся индивидуальными.

09
Новая тема

Чем могут быть значения?

font-size: 30px; width: 20%число с единицами измерения
color: red; rgb(255, 0, 0)цвет — ключевым словом или в формате RGB
url("images/fon.jpg")адрес файла: изображение, текстура, звук…
italic; center; no-repeatключевое слово — пишется без кавычек

Например, фон страницы: body { background: url('bokeh.jpg'); }

10
Новая тема

Числа и единицы измерения

width: 20%проценты — относительно ширины родителя
font-size: 30pxпиксели — самая частая единица 🔥
font-size: 1.5emem — относительно текущего размера (здесь 150%)
font-size: 24ptпункты (1 pt = 1/72 дюйма) — обычно для печати ○
margin-left: 30mmмиллиметры — в вебе используется редко ○

Запомни главное: px — чаще всего, % и em — часто, pt и mm — редко.

11
Новая тема

Цвет: три способа

color: red; color: aqua;1. ключевое слово — браузеры знают цвета по имени 🔥
color: rgb(0, 255, 170);2. RGB в десятичной системе
color: #00FFAA;3. RGB в шестнадцатеричной системе — чаще всего в коде 🔥

🌈 Модель RGB

Цвет — смесь трёх лучей: красного, зелёного и синего. Каждый компонент — от 0 до 255. rgb(0, 255, 170) и #00FFAA — один и тот же цвет в разных системах счисления.

12
Новая тема

А если нужны разные стили?

Ситуация: часть абзацев нужно оформить по особым правилам — уменьшенный курсивный шрифт, серый фон и небольшой сдвиг вправо.

И тут тебе так понравилась идея, что ты хочешь применить этот же стиль ещё и к некоторым заголовкам, цитатам и спискам!

😕 В чём загвоздка?

Тег <p> всего один, и стиль у него может быть только один — на все абзацы сразу.

❓ Вопрос

Можно ли применять одно и то же оформление выборочно к разным тегам?

13
Решение

Классы CSS

Классы настраивают одинаковое оформление для группы или подгруппы элементов. Класс — атрибут тега, связывающий элемент со стилем.

.example { font-style: italic; background-color: #eeeeee; }

<p class="example">Особый абзац</p>
<h2 class="example">Заголовок с тем же стилем</h2>

Без привязки к тегу

.example { } — стиль применится к любому элементу с class="example".

С привязкой к тегу

p.example { } — только к абзацам с этим классом.

14
Часто используемые свойства

Оформляем текст

p {
    color: rgb(0, 0, 255);
    background-color: aqua;
    font-size: 40px;
    font-weight: 700;
    font-style: italic;
}
  • color — цвет текста;
  • background-color — цвет фона;
  • font-size — размер: px, pt, em или слова small / medium / large;
  • font-weight — насыщенность 100–900, шаг 100 (700 = жирный);
  • font-style — normal или italic.
15
Часто используемые свойства

Отступы: padding и margin

margin — внешние отступы
border — граница
padding — внутренние отступы
содержимое элемента (текст)
  • padding-left / -right / -top / -bottom — поле внутри элемента, от края до содержимого;
  • margin-left / -right / -top / -bottom — отступ снаружи, до соседних элементов.

На практике чаще используют сокращённую запись: padding: 10px 20px; и margin: 15px auto;

16
Часто используемые свойства

Размеры и рамки

  • width и height — ширина и высота блочных элементов (без границ и отступов);
  • border — толщина, стиль и цвет границы одной строкой;
  • только одна сторона: border-top, border-bottom, border-left, border-right;
  • border-radius — скругление уголков (без рамки скругляется фон).
.card {
    width: 300px;
    height: 150px;
    border: 3px solid navy;
    border-radius: 12px;
}
