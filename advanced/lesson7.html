  • Принимать данные через HTML-формы (POST).

  • Делать SQL-запросы к базе данных.

🚧 В чем проблема сейчас?

Чтобы показать вопрос или список викторин, мы пишем HTML прямо внутри Python-кода, склеивая строки:

html = "<h1>" + title + "</h1>"

Это ужасно неудобно!

Почему «склеивать» HTML в Python — это плохо?

⚠️ Минусы подхода «от данных к тегам»

  • Каша в коде: Очень легко забыть закрывающую кавычку или тег, и всё сломается.
  • Сложно менять дизайн: Чтобы поменять цвет кнопки, нужно лезть в Python-код.
  • Нельзя разделить роли: Дизайнер не может верстать страницу, пока программист пишет бэкенд.
Аналогия: Это как строить дом, постоянно бегая за бетоном в другой город, вместо того чтобы привезти готовые блоки на стройку.

Решение: HTML-Шаблоны 📄

Шаблон — это обычный HTML-файл, в котором есть «дырки» (места) для данных. Шаблон отвечает только за внешний вид.

🐍 Python (Flask)

Отвечает за логику: берет данные из БД, считает баллы, принимает решения.

«Вот данные, отрисуй их красиво».

🎨 HTML (Шаблон)

Отвечает за дизайн: расставляет теги, стили, кнопки.

«Я готов принять любые данные и красиво их показать».

Структура папок и `render_template`

Flask очень строг к порядку файлов. Шаблоны должны лежать в специальной папке.

📁 Структура на диске

my_project/
├── app.py          # Наш Python код
├── templates/      # 📂 Сюда кладем HTML!
│   ├── index.html
│   └── test.html
└── static/         # 📂 Картинки, CSS
    └── style.css

⚙️ Код во Flask

Используем функцию render_template, чтобы «собрать» страницу.

from flask import render_template

def index():
    # Передаем данные в шаблон
    return render_template(
        'index.html', 
        title="Викторина"
    )

Движок Jinja2: Переменные `{{ }}`

Внутри HTML-шаблона мы используем двойные фигурные скобки {{ }}, чтобы сказать Flask: «Вставь сюда значение переменной».

📄 Шаблон (index.html)

<h1>{{ title }}</h1>
<p>Привет, {{ username }}!</p>

🐍 Python (app.py)

return render_template(
    'index.html',
    title="Главная",
    username="Вася"
)
Важно: Имя переменной в Python и в HTML должно совпадать! Можно передавать строки, числа, списки и словари.

Условия в шаблонах: `{% if %}`

Иногда нужно показать блок кода только при определенном условии (например, если пользователь авторизован). Для этого используем одинарные скобки с процентом {% %}.

<body>
  {% if is_logged_in %}
    <p>Привет, {{ username }}!</p>
  {% else %}
    <p>Пожалуйста, войдите.</p>
  {% endif %}
</body>

Операторы (==, >, and, or) работают точно так же, как в обычном Python!

Циклы в шаблонах: `{% for %}`

Чтобы вывести список (например, варианты ответов или список викторин), используем цикл.

<ul>
  {% for quiz in quizzes_list %}
    <li>{{ quiz.name }}</li>
  {% endfor %}
</ul>
Как это работает: Flask берет список quizzes_list, который мы передали из Python, и для каждого элемента создает кусочек HTML, подставляя его имя.

Подключаем CSS (Статические файлы)

Чтобы сайт был красивым, нужно подключить CSS. Файлы стилей лежат в папке static/. Чтобы получить на них ссылку, используем функцию url_for прямо в HTML.

<head>
  <!-- Ссылка на файл static/style.css -->
  <link rel="stylesheet" 
        href="{{ url_for('static', filename='style.css') }}">
</head>

url_for('static', ...) — это встроенная функция Flask, которая сама знает, где лежит папка static, и формирует правильный URL.

Практика: Шаблон страницы вопроса

Нам нужно показать текст вопроса и варианты ответов (радиокнопки). Но варианты нужно перемешать, чтобы правильный ответ не был всегда первым!

🐍 Python (Перемешиваем)

from random import shuffle

def test():
    answers = ["Правильный", "Нет", "Не знаю"]
    shuffle(answers) # <-- Перемешали!
    
    return render_template('test.html',
        question="Сколько будет 2+2?",
        answers_list=answers
    )

🎨 HTML (test.html)

<h2>{{ question }}</h2>
<form method="POST">
  
  {% for ans in answers_list %}
    <input type="radio" name="answer" 
           value="{{ ans }}">
    {{ ans }}
  {% endfor %}

  <button>Ответить</button>
</form>

⚠️ Проблема: Как передать ID вопроса?

Когда пользователь нажимает «Ответить», сервер должен понять, на какой именно вопрос он ответил. Но мы не хотим показывать ID вопроса пользователю на экране!

Решение: Скрытое поле (`type="hidden"`)

Это элемент формы, который не виден на странице, но его значение отправляется на сервер вместе с остальными данными.

<!-- Пользователь этого не видит, но браузер отправит q_id=17 на сервер -->
<input type="hidden" name="q_id" value="{{ question_id }}">

Обработка ответа на сервере

Функция test() теперь работает как «развилка». Если пришел POST-запрос, значит, пользователь ответил.

def test():
    if request.method == 'POST':
        # 1. Читаем скрытый ID вопроса и текст ответа
        q_id = request.form.get('q_id')
        user_answer = request.form.get('answer')
        
        # 2. Проверяем ответ (запрос к БД)
        if check_answer(q_id, user_answer):
            session['score'] += 1
            
        # 3. Переходим к следующему вопросу или к результату
        next_q = get_next_question()
        if not next_q:
            return redirect(url_for('result'))
        # ... (иначе рендерим следующий вопрос)

Проверка ответа через SQL

Функция check_answer() берет ID вопроса, находит в БД правильный ответ и сравнивает с тем, что прислал пользователь.

def check_answer(q_id, user_ans):
    # SQL-запрос: найти правильный ответ по ID вопроса
    query = '''SELECT question.answer 
               FROM quiz_content, question
               WHERE quiz_content.id = ? 
               AND quiz_content.question_id = question.id'''
    
    result = execute_query(query, (q_id,))
    correct_answer = result[0]
    
    # Сравниваем и возвращаем True или False
    return correct_answer == user_ans

Так как варианты перемешаны в HTML, пользователь не может просто посмотреть код страницы и узнать правильный ответ!

Финал: Страница результатов

Когда вопросы закончились, мы перенаправляем пользователя на /result. Там мы просто берем данные из сессии и показываем их.

🐍 Python

def result():
    return render_template(
        'result.html',
        total=session.get('total', 0),
        score=session.get('score', 0)
    )

🎨 HTML (result.html)

<h1>Викторина завершена!</h1>
<p>
  Вы ответили на {{ total }} вопросов.
</p>
<p>
  Правильных ответов: {{ score }}
</p>
<a href="/">Пройти еще раз</a>

Итоги урока

  • Шаблоны отделяют дизайн (HTML) от логики (Python). Это делает код чистым.
  • Файлы шаблонов лежат в папке templates/, а стили/картинки в static/.
  • Функция render_template() «скармливает» данные в HTML.
  • Движок Jinja2 позволяет использовать переменные {{ }}, условия {% if %} и циклы {% for %} прямо внутри HTML.
  • Скрытые поля (type="hidden") помогают передавать служебные данные (например, ID) на сервер, не показывая их пользователю.
