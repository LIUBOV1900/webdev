️ Схема связей базы данных «Викторины»

Точные связи по полям внешних ключей

quiz
Справочник викторин
🔑 id INTEGER PK
name VARCHAR
❓
question
Банк вопросов
🔑 id INTEGER PK
question VARCHAR
answer VARCHAR
wrong1 VARCHAR
wrong2 VARCHAR
wrong3 VARCHAR
🔗
quiz_content
Связи викторин и вопросов (M:N)
🔑 id INTEGER PK
🔗 quiz_id INTEGER FK → quiz.id
🔗 question_id INTEGER FK → question.id

📐 Описание связей по полям

quiz.id ─── quiz_content.quiz_id Одна викторина (quiz) содержит много записей в quiz_content
question.id ──── quiz_content.question_id Один вопрос (question) может входить в много записей quiz_content
quiz M ──── N question Связь «многие-ко-многим» через промежуточную таблицу quiz_content
PK — первичный ключ (подсвечен красным)
FK — внешний ключ (подсвечен синим)
Связь quiz.id ↔ quiz_content.quiz_id
Связь question.id ↔ quiz_content.question_id
