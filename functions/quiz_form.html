Цель функции: взять данные из базы и превратить их в HTML-код, который покажет пользователю форму выбора викторины

Что возвращает функция?

return html  # строка с HTML-кодом

📦 Шаг 1: Получение списка викторин

1

Вызов функции get_quises()

q_list = get_quises()

Что возвращает get_quises()?

Список кортежей (id, name) из базы данных:

q_list = [
    (1, "Столицы мира"),
    (2, "Флаги стран"),
    (3, "Реки России")
]
id

Уникальный номер викторины в базе

name

Название викторины (показывается пользователю)

Шаг 2: Формирование option через f-строки

2

Цикл по всем викторинам

options = ''

for id, name in q_list:
    options += f'<option value="{id}">{name}</option>\n'

Как работает f-строка?

Подставляем id и name прямо в HTML-тег:

Итерация 1 
id=1, name="Столицы мира"
→ <option value="1">Столицы мира</option>
Итерация 2 
id=2, name="Флаги стран"
→ <option value="2">Флаги стран</option>

Результат: переменная options накапливает все option через +=, каждый с новой строки (\n)

🌐 Шаг 3: Сборка итогового HTML

3

Вставляем options в HTML-шаблон

html = f'''<html>
<body>
    <h2>Выберите викторину:</h2>
    <form method="post" action="index">
        <select name="quiz">
            {options}
        </select>
        <p><input type="submit" value="Выбрать"></p>
    </form>
</body>
</html>'''

Что в итоге получается?

<html> <body> <h2>Выберите викторину:</h2> <form method="post" action="index"> <select name="quiz"> <option value="1">Столицы мира</option> <option value="2">Флаги стран</option> <option value="3">Реки России</option> </select> <p><input type="submit" value="Выбрать"></p> </form> </body> </html>

👁️ Как это видит пользователь в браузере

Выберите викторину:

💡 Ключевая идея:
Строки 6-8 (выделены зелёным) — динамически сгенерированы функцией из данных базы. Если в базе 10 викторин — будет 10 строк <option>.

✨ Итог: что делает quiz_form()

Вход

База данных с викторинами

Обработка

Цикл + f-строки → option

Выход

Готовая HTML-страница

Ключевые приёмы:

  • f-строки — вставка переменных прямо в HTML-теги
  • Накопление строки — options += ... в цикле
  • Многострочные f-строки — f'''...''' для шаблона HTML
  • Вставка готовой строки — {options} в шаблон

💡 Главная идея: функция динамически создаёт HTML на основе данных из базы — сколько викторин в БД, столько option будет на странице
