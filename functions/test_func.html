Что делает функция test()?

Это главный контроллер викторины. Она обрабатывает маршрут /test и отвечает за два действия:

📋 Отображение вопроса

Достаёт из базы данных следующий вопрос и показывает его пользователю.

✅ Обработку ответа

Принимает ответ пользователя, проверяет его и сохраняет результат в сессию.

Функция реагирует и на GET (просто зашли на страницу), и на POST (отправили ответ).

Шаг 1. Проверка: выбрана ли викторина?

if not ('quiz' in session) or int(session['quiz']) < 0:
    return redirect(url_for('index'))

Это «защита от дурака». Если пользователь вручную вбил /test в адресную строку:

  • в сессии нет ключа 'quiz', ИЛИ
  • значение 'quiz' равно -1 (устанавливается функцией index()).

В обоих случаях — редирект обратно на главную страницу.

Шаг 2. Обработка ответа (POST)

if request.method == 'POST':
    save_answers()

Если пользователь нажал «Ответить», браузер отправляет POST-запрос. Тогда вызывается save_answers(), которая:

  • забирает выбранный ответ из формы;
  • проверяет его на правильность;
  • увеличивает счётчики total и answers;
  • обновляет last_question — ID только что отвеченного вопроса.

Если это GET-запрос — блок пропускается.

Шаг 3. Получение следующего вопроса

next_question = get_question_after(
    session['last_question'],
    session['quiz']
)

Теперь нужно достать из базы данных следующий вопрос.

Функция get_question_after ищет вопрос, ID которого больше, чем session['last_question'], в рамках текущей викторины.

Шаг 4. Вопросы закончились?

if next_question is None or len(next_question) == 0:
    return redirect(url_for('result'))

Если база не нашла больше вопросов (вернула None или пустой список) — викторина пройдена.

Пользователь перенаправляется на страницу результатов (/result), где увидит свой счёт.

Шаг 5. Отображение вопроса

else:
    return question_form(next_question)

Если следующий вопрос успешно получен — вызываем question_form():

  • берёт текст вопроса;
  • перемешивает варианты ответов (каждый раз в новом порядке);
  • рендерит HTML-шаблон test.html;
  • отправляет его в браузер пользователя.

Краткая схема работы

1Зашёл на /test? → Проверь, выбрал ли викторину. Нет → выгони на главную.
2Пришёл ответ (POST)? → Проверь ответ, сохрани результат в сессию.
3Достань следующий вопрос из БД.
4Вопросов больше нет? → Отправь на страницу результатов.
5Вопрос есть? → Покажи его пользователю.
